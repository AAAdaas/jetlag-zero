# JETLAG ZERO v2.1

日本語・英語OCR対応。スクショから経路を抽出し、複数区間を入力候補として表示します。

## GitHub Pagesへの更新
ZIP内の `index.html` `sw.js` `manifest.webmanifest` `icon.svg` `README.md` をリポジトリのルートに上書きしてください。既存の `app.js` はv2.0では使用されていないため、残っていても動作に影響しません。

## 注意
日本語OCRは初回にインターネット接続が必要です。旅行日程の表示だけではフライトの出発・到着時刻が確定しない場合があります。未確認の時刻は自動で埋めません。実際の航空券と照合してください。
