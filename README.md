# JETLAG ZERO v2.2

## 変更点
- タイムラインの各行に、出発地と最終目的地の日時を併記
- 機内行動に「出発から +N時間MM分」と区間内経過時間を表示
- 機内画面に出発地・最終目的地の2つの時計と日付を表示
- 日時を `YYYYMMDD HHMM` 形式で直接入力（例 `20261213 2155`）
- 入力途中にフォームを描画し直さないよう改善

既存のOCR、乗継便、睡眠サウンドは維持。時差ぼけアドバイスは一般的な目安であり、医療的個別最適化ではありません。

## 公開
ZIP内の5ファイルをGitHubリポジトリのルートにアップロードして置き換え、GitHub Pagesの公開完了後に再読み込みしてください。
